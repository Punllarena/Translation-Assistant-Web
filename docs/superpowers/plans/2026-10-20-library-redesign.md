# Library Redesign Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** The Library shows series only (Bookshelf or Compact list); a series opens on a two-pane Volumes view with volume-level publish/export and per-chapter actions behind menus; every document must belong to a series; chapters are numbered per volume.

**Architecture:** Backend first: `documents.series_id` becomes `NOT NULL ON DELETE CASCADE` (a migration adopts orphans into one-chapter series), a single `arrange()` in `api/library.py` keeps each volume a contiguous run of `series_order` after every write that can break it (skipped for syosetu series), and two ZIP exports plus `cover_image_id` / `GET /volumes` feed the new screens. Frontend: pure helpers (`shelf.ts`, `volumes.ts`, `viewPref.ts`) carry the logic and the vitest coverage; React components are thin. One `<dialog>`-based `ui/Dialog.tsx` replaces every `window.prompt`/`window.confirm` under `web/src/library/`.

**Tech Stack:** FastAPI, SQLAlchemy 2, Alembic, Postgres, pytest; React 19 + TanStack Query + react-router, vitest, Playwright.

**Spec:** `docs/superpowers/specs/2026-10-20-library-redesign-design.md` (mockups in `.superpowers/brainstorm/75-1792486555/content/`: `library-layout.html` options A and C, `series-layout-v2.html`, `chapter-actions.html`).

## Global Constraints

- Handlers `flush()`, never `commit()`; routers built with `api_router()`; tenancy through `scoped()` (404 for another user's ids in the path, 422 for ids in a body).
- No Python module over ~400 lines. `api/routers/transfer.py` is 309 lines: the ZIP exports move to a new `api/routers/exports.py`.
- Migrations: change the model, `alembic revision --autogenerate`, then add the data step by hand **before** the generated `alter_column` (a data step can't be autogenerated; the rule against hand-patching is about schema).
- After API changes: `cd web && npm run gen:api` (venv on `PATH`).
- Stylesheets use tokens from `web/src/styles/tokens.css`, never literal colours. New library styles go in `web/src/styles/library.css`, imported from `index.css`.
- Run pytest with `TA_MT_ALLOW_PRIVATE_URLS=false TA_WP_ALLOW_PRIVATE_URLS=false`.
- vitest covers pure modules only; components are covered by Playwright.
- E2E: each spec owns its seeded rows in `tools/e2e_seed.py`; seed names must not contain "E2E chapter" (except the existing one); `ta_e2e` is reset once per run, so a spec must not destroy seeded rows another run needs.
- Exact copy (spec):
  - Delete series dialog: `Delete "<title>" and its N chapters? This can't be undone.`, confirm button `Delete series and N chapters`.
  - Bulk delete: `Delete N chapters? This can't be undone.`
  - Library localStorage key: `ta.libraryView` (`"shelf"` | `"list"`, default `"shelf"`).
  - Series page URL: `?tab=volumes|tools|settings` (default `volumes`) and `&volume=<id>|none`.
  - Narrow breakpoint: 768 px.

## Review Focus

- **A series with volumes *and* chapters in no volume:** loose chapters sort after the last volume and show under a "No volume" entry, numbered from 1. → Task 2 `test_loose_chapters_follow_the_last_volume`; Task 5 `volumeGroups puts loose chapters last as "none"`.
- **A syosetu series:** reorder / renumber-by-title are 409, moving between volumes keeps `series_order`, so a re-fetch skips what it has. → Task 2 `test_syosetu_series_keeps_its_numbers`.
- **Migration title collisions:** an orphan titled like an existing series, and two orphans with the same title, get ` (2)`, ` (3)`. → Task 1 `test_free_title_appends_the_first_free_suffix`.
- **An empty series** (0 chapters, no volumes) on the shelf: `0 ch`, progress 0, title tile, no crash. → Task 5 `seriesCards handles an empty series`.
- **Exports of ids that aren't the caller's:** volume ZIP of another user's volume is 404; selection ZIP with a foreign id is 422 with the same body as a missing id. → Task 3 tests.

**Interfaces:**
- Produces (`shelf.ts`):
  ```ts
  export type Doc = Schemas["DocumentListItem"]; export type SeriesRow = Schemas["SeriesOut"]; export type Volume = Schemas["VolumeOut"];
  export interface SeriesCard { series: SeriesRow; coverImageId: number | null; volumeCount: number; chapterCount: number; progress: number; editedAt: string | null }
  export function seriesCards(series: SeriesRow[], docs: Doc[], volumes: Volume[], filter: string): SeriesCard[]
  export function sizeLabel(card: SeriesCard): string   // "1 vol · 21 ch" | "212 ch" | "0 ch"
  ```
  Cards in natural title order (`Intl.Collator`, numeric); filter matches series title, case-insensitive. Progress = Σtranslated_count·100 / Σline_count, floored; 0 when no lines. Cover: first volume (by `volume_order, id`) → first chapter in it (by `series_order, id`) with `cover_image_id`; else first chapter of the series with one; else `null`. `editedAt` = max `updated_at`.
- Produces (`volumes.ts`):
  ```ts
  export type VolumeKey = number | "none";
  export interface VolumeGroup { key: VolumeKey; volume: Volume | null; docs: Doc[]; coverImageId: number | null; progress: number }
  export function volumeGroups(seriesId: number, docs: Doc[], volumes: Volume[]): VolumeGroup[]
  export function chapterNumber(group: VolumeGroup, doc: Doc, syosetu: boolean): number
  export function pickVolume(param: string | null, groups: VolumeGroup[]): VolumeKey | null
  ```
  Groups follow `volume_order, id`, then `"none"` only if loose chapters exist; a series with no volumes yields one `"none"` group. Docs in `series_order, id`. `chapterNumber`: `syosetu ? doc.series_order : index in group + 1`. `pickVolume`: the param if it names a group, else the first group's key, `null` when there are no groups.
- Produces (`viewPref.ts`): `export type LibraryView = "shelf" | "list"; export function readView(storage?: Pick<Storage, "getItem">): LibraryView; export function writeView(v: LibraryView, storage?: Pick<Storage, "setItem">): void` — key `ta.libraryView`, default `"shelf"`, unknown values read as `"shelf"`, any thrown storage error swallowed; `storage` defaults to `localStorage` accessed inside try/catch.
