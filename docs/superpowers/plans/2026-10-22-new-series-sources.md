# New Series Sources Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** New series asks whether the translation starts from syosetu, an EPUB, or pasted text, and runs a flow for each. Series also record the original Japanese title, author, and author romaji.

**Architecture:** Three new `Series` text columns flow through the series API, the EPUB import (new-series mode) and EPUB export (author fallback, `dc:source` credit). Syosetu gets a read-only `POST /scrape/syosetu/novel` that parses the index page header, plus a short-story path shared by the read endpoint, the chapter list and the fetch job. The SPA replaces the New series prompt with a `/new` page: a three-way chooser, then one flow component per source, all sharing a `SeriesFields` block.

**Tech Stack:** FastAPI, SQLAlchemy 2, Alembic, Postgres, BeautifulSoup, pytest; React + TanStack Query + openapi-fetch, Vitest, Playwright.

**Spec:** `docs/superpowers/specs/2026-10-22-new-series-sources-design.md`

## Global Constraints

- Columns: `series.original_title`, `series.original_author`, `series.author_romaji`. Each is `Text NOT NULL DEFAULT ''`, using both `default=""` and `server_default=""`.
- API field type for all three: `Credit = Annotated[str, StringConstraints(strip_whitespace=True, max_length=300, pattern=r"^[^\x00]*$")]`, in `api/schemas/common.py`. The default is `""`.
- Translated title stays `Title` (required, 1–300). A taken title on create returns 409 with `TITLE_TAKEN = "a series with that title exists"` (`api/routers/series.py`).
- One Alembic revision, autogenerated, with `down_revision = 'c5af30ce0a6b'`.
- Handlers only `flush()`. Routers use `api_router()`. Syosetu request paths use `_slot()` and `server_settings.effective(db).syosetu_delay_seconds`.
- Tests never hit live syosetu. They use `httpx.MockTransport` through `scrape.client(transport=...)` and the `site` fixture in `tests/test_scrape_api.py`.
- No Python module over ~400 lines. Today `api/routers/epub.py` has 305 lines and `api/core/scrape.py` has 188.
- Run `npm run gen:api` after API changes and commit `web/src/api/schema.d.ts` with them.
- Copy strings (exact):
  - Chooser cards: **Syosetu** "Start from a syosetu URL and fetch the first chapter." · **EPUB** "Start from an EPUB of a volume you have." · **Paste** "Start empty and paste chapters in yourself."
  - Field labels: "Title", "Japanese title", "Author", "Author (romaji)".
  - Short story with no more chapters (Tools tab): "This is a short story; there are no more chapters to fetch."
- Commit messages end with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.
- Tasks 1–5 are backend. **The full `pytest` and `ruff check .` must pass at the end of Task 5.** The SPA tasks (6–9) must pass `npm test`, `npx tsc --noEmit` and `npm run e2e` at the end of Task 9.

## Review Focus

1. **A syosetu URL that is a chapter page or another host** must give a 422 from the read endpoint, never a 500, and never create a series. Pinned in Task 3 (`test_novel_read_refuses_chapter_and_foreign_urls`).
2. **A root page with neither an index nor novel text** (deleted novel, login wall) must give a 422 "no chapters found", not an empty success the SPA would turn into a chapterless series. Pinned in Task 3 (`test_novel_read_with_nothing_is_422`).
3. **New-series EPUB import with a title the user already has** must give a 409 and write nothing, while the Import page's find-or-create keeps working. Pinned in Task 4 (`test_new_series_mode_refuses_taken_title`, `test_import_page_still_reuses_series`).
4. **Fetching chapter 1 for a short story twice** (double click, retry after an error) must not create two chapters. Pinned in Task 3 (`test_short_story_fetch_is_idempotent`).
5. **Blank credit fields must not emit empty `<dc:source></dc:source>` or `<dc:creator>`** in exported EPUBs. Pinned in Task 5 (`test_blank_credits_emit_nothing`).

### Task 2: Syosetu novel header and short stories in the scraper

**Interfaces:**
- Produces:
  - `read_novel(c: httpx.Client, url: str) -> dict`. It validates with `_validate_series_url`, GETs **the root page once**, and returns `{"title": str, "author": str, "short_story": bool, "chapters": list[dict]}`. `chapters` is the **first index page's** entries in the `_extract_chapters` shape (`num`, `title`, `url`, `group`), sorted by `num`. For a short story it is `[{"num": 1, "title": <title>, "url": <url as given>, "group": None}]`. Author: the `<a>` text inside `div.p-novel__author` when present, else that div's text with a leading `作者：` (and the ASCII `作者:`) removed and stripped. Use `""` when absent.
  - Private helper `_has_novel_text(soup) -> bool`: the same `js-novel-text` / `p-novel__text` test that `fetch_syosetu` uses.
