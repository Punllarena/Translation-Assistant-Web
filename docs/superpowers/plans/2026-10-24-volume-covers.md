# Volume Covers Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Covers live on volumes (upload, fetch by image address, clear), the user picks which volume's cover is the series cover, and every cover consumer reads the volume cover.

**Architecture:** New `volume_covers` table (one row per volume) and a `volumes.is_series_cover` flag; `document_images.is_cover` is migrated away and dropped. Cover routes live in a new `api/routers/covers.py`, the link download in `api/covers.py`. The SPA reads `cover_id` / `is_series_cover` from `VolumeOut`.

**Tech Stack:** FastAPI, SQLAlchemy 2, Alembic, Postgres, httpx; React + TanStack Query, vitest.

**Spec:** `docs/superpowers/specs/2026-10-24-volume-covers-design.md`

## Global Constraints

- Handlers `flush()`, never `commit()`; routers built with `api_router()`; `scoped()` / `scoped_volume()` for tenancy (404 for foreign ids).
- Migration autogenerated; data step added between the create and the drop.
- No Python module over ~400 lines.
- Covers: PNG/JPEG/GIF/WebP by `sniff_image`, ≤ 10 MiB; links: `check_user_url(url, False, "image")` on every hop, ≤ 3 redirects, ~20 s timeout.
- Page-link error copy: "That link is a web page, not an image. Open the image, right-click it and copy the image address."
- Tests: `httpx.MockTransport`, never the network; Postgres at 127.0.0.1; one pytest run at a time.

## Review Focus

- A link whose server sends a huge body with no Content-Length → stop at 10 MiB, 413 (test in Task 2).
- A redirect to `127.0.0.1` / a private address → refused before the hop is sent (Task 2).
- Merging two volumes that both have covers, one of them the series cover → kept volume ends with one cover and the flag (Task 3).
- A series whose chosen volume has no cover → bookshelf falls back to the first volume with one (Task 4 vitest).
- Existing data: a volume with covers on two chapters plus a loose-chapter cover → one volume cover, two excluded images, no lost rows (Task 1 manual check).

### Task 2: Cover API

**Files:** Create `api/covers.py`, `api/routers/covers.py`, `tests/test_covers.py`; Modify `api/schemas/volumes.py` (`VolumeCoverOut{id, volume_id, src_path}`, `CoverUrl{url}`, `SeriesCoverVolume{volume_id: int|None}`, `VolumeOut.cover_id`, `VolumeOut.is_series_cover`), `api/main.py` (include router), `api/routers/volumes.py` (drop document cover routes and `CoverOut`), `api/routers/documents.py` and `api/schemas/documents.py` (drop `has_cover`, `cover_image_id`), `api/schemas/images.py` (drop `is_cover`).

**Produces:**
- `covers.fetch_image(c: httpx.Client, url: str) -> tuple[bytes, str]` (data, src_path); raises `CoverFetchError(status, message)`.
- `covers.client(transport=None) -> httpx.Client` (redirects followed, max 3, request hook runs `check_user_url`).
- `covers.set_cover(db, volume, data, src_path) -> VolumeCover` (replace).
- `covers.effective_series_cover(db, series_id) -> VolumeCover | None` (flagged volume's cover, else first by `volume_order, id`).
- Routes: `PUT /volumes/{id}/cover` (file), `POST /volumes/{id}/cover/url`, `DELETE /volumes/{id}/cover` (204), `GET /covers/{id}`, `PUT /series/{id}/cover-volume` (204). Seam: `covers.http_client` dependency overridden in tests.

Tests (`tests/test_covers.py`): upload PNG → `VolumeOut.cover_id` set and `GET /covers/{id}` returns bytes with immutable cache headers; replace gives a new id; non-image 415; delete 204 twice; foreign volume/cover 404; URL fetch of PNG works; HTML answer → 422 with the copy above; >10 MiB streamed → 413; redirect to `http://127.0.0.1/` → 422 and the transport never sees the hop; upstream 404 → 502; `cover-volume` sets one flag, moves it, clears with null, 422 for another series' volume; `effective_series_cover` falls back when the flagged volume has none.

- [ ] Write tests; run, see them fail; implement; run `pytest tests/test_covers.py`; fix the old cover tests in `tests/test_volumes.py` / `tests/test_documents.py` (delete the document-cover ones); commit.
