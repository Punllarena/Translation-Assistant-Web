# Phase 5 — Aggregator Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship spec §8, the machine-translation aggregator. The editor shows, for the active line, live results from DeepL, LibreTranslate and Ollama, plus word-by-word analysis from MeCab and JParser. Results stream over SSE and are cached in `mt_cache`. Each user brings their own credentials and endpoints, and a backend that isn't configured says so instead of failing.

**Architecture:**
- **`api/mt/` package:**
  - `base.py`: events, availability, and the translator protocol.
  - `languages.py`: language names and the DeepL code map, ported from the desktop's `ta/config/languages.py`.
  - `cache.py`: `mt_cache` get and put.
  - One module per backend, each taking an injected `httpx.AsyncClient`. Tests use `httpx.MockTransport` fixtures and never call a live endpoint.
  - `jparser.py`: the desktop edict2 lookup, ported.
  - `mecab.py`: fugashi tokenization.
  - Both analyzers return structured entries, not HTML.
- **`api/routers/mt.py`:**
  - `GET /mt/backends` reports per-user availability and the language list.
  - `GET /mt/stream` is the SSE endpoint, async.
- **SPA:**
  - A Machine translation settings page.
  - An MT panel stack in the editor's side column, under the TM panel.

**Tech Stack:**
- FastAPI (async route, `StreamingResponse` SSE), httpx (now a runtime dependency).
- SQLAlchemy 2.0 / Postgres (`mt_cache` already exists).
- fugashi + unidic-lite (`mecab` extra).
- React 19, TanStack Query, `EventSource`, vitest, Playwright.

**Spec:** `docs/superpowers/specs/2026-10-10-web-app-port-design.md` (§8, §12 "MT backends are tested against recorded fixtures", §13; phases in §15)

## Global Constraints

- **Routers:**
  - Every router is built with `api_router()`. Handlers `flush()` and never `commit()`.
  - `tests/test_commit_boundary.py` must keep passing.
- **Tenancy:**
  - Fetch user-owned rows with `scoped()`; an id in a request body or query goes through `owned_ref()`.
  - Another user's id is a 404, never a 403.
  - A request uses only the requesting user's credentials and settings.
- **Secrets:**
  - Credential secrets never appear in any response, SSE event, or log line. Error events say what failed, never with what key.
- **Testing:**
  - No live network in tests.
  - Every HTTP backend takes an `httpx.AsyncClient`, and tests pass one built on `httpx.MockTransport` that replays recorded JSON (spec §12).
- **Module size:** no Python module over ~400 lines.
- **Migrations:** autogenerated only. This phase should need none: `mt_cache` and `api_credentials` already exist.
- **API types:** run `npm run gen:api` (in `web/`) after API changes the SPA consumes. Commit `web/src/api/schema.d.ts`; `web/openapi.json` is gitignored.
- **Environment:**
  - venv `.venv` with `.[dev,mecab]`, and `TA_SECRET_KEY=dev-secret-key-at-least-32-characters-long`.
  - Postgres runs on localhost:5432. Never run `docker compose down`.
  - `pytest -q` prints only dots, so judge a run by its exit code.
- **Commit trailer:** a `Co-Authored-By` line for the authoring model, plus:
  ```

  ```

  - `ta/translators/{base,deepl,libretranslate,ollama,mecab,jparser}.py`

## Rulings (decided while planning; user choices marked ✔)

1. ✔ **Google and Bing are not shipped.** Backends are DeepL, LibreTranslate, Ollama, MeCab and JParser. The spec's "unofficial endpoints" limitation no longer applies; Task 10 notes this in the spec.
2. ✔ **MeCab and JParser return structured entries:**
   - Each entry is `{surface, reading, lemma, pos, gloss, tense, base_form, matched}`.
   - React renders them; there is no server-built HTML.
   - The desktop's `_fmt` and `format_entry` become dict builders. The parsing, deconjugation and greedy segmentation are ported verbatim.
3. ✔ **No Ollama prefetch of upcoming lines.** The active line only, cached.
4. ✔ **Endpoint URLs:**
   - **Per-user override:** the credential's `endpoint_url` for kinds `ollama` and `libretranslate`.
   - **Server default:** `TA_OLLAMA_URL` (default `http://localhost:11434`) and `TA_LIBRETRANSLATE_URL` (default empty, which means not configured).
   - **Secrets:**
     - `ollama` and `libretranslate` credentials may have an empty secret. LibreTranslate's key is optional, and an Ollama secret, if set, is sent as a bearer token for proxied hosts.
     - `deepl` and `wordpress` still require a secret.
5. **DeepL goes over httpx, not the `deepl` SDK.**
   - Reason: no new dependency, and it is fixture-testable.
   - Host: a key ending in `:fx` uses `https://api-free.deepl.com`, anything else `https://api.deepl.com`.
   - Request: `POST /v2/translate` with `Authorization: DeepL-Auth-Key <key>`.
6. **What gets translated is the line as the editor displays it** (desktop `source_sentence_changed`): `display_text` with the editor profile's glossary applied, `%`/`$` stripped, then trimmed. The request carries the same optional `profile_id` the editor uses. A blank result sends `done` with no backend call.
7. **Languages:**
   - Source: the document's `source_language` (default `ja`).
   - Target: the user setting `mt_target` (default `en`), which must be a code in `api.mt.languages.LANGUAGES`.
   - Ollama's `{src}`/`{dst}` placeholders get the desktop `_lang_display` form, e.g. `Japanese (ja)`.
8. **Caching:**
   - Only the HTTP backends are cached. The analyzers are local and deterministic, and their output is JSON-shaped.
   - Cache `backend` key values:
     - `deepl`
     - `libretranslate`
     - `ollama:<model>:<sha256(system_prompt)[:12]>`, so two users with different models or prompts never share a result.
   - Ollama is cached only when the stream completes. A failure or disconnect writes nothing.
   - A cache hit sends one `result` event and `done {cached: true}`.
9. **User settings (schema-free store):**
   - `mt_target`: default `"en"`.
   - `mt_enabled`: an ordered list of backend names, default `["mecab", "jparser"]`, matching the desktop defaults.
   - `ollama_model`: default `""`, which means needs setup.
   - `ollama_system_prompt`: default is the desktop `DEFAULT_OLLAMA_SYSTEM_PROMPT`.
10. **The SSE stream writes `mt_cache` in its own short session** (`SessionLocal()` with an explicit commit). This is the one sanctioned exception to "handlers never commit": the stream finishes after the response has started, when the request session is gone. The router imports `SessionLocal` by name so tests can swap it.
11. **SSE wire format:**
    - Frame: `event: <type>\ndata: <json>\n\n`. `data` is always JSON, so newlines in model output cannot break framing.
    - Types:
      - `chunk {text}`
      - `thinking {text}`
      - `result {text}`
      - `analysis {entries}`
      - `needs_setup {message}`
      - `error {message}`
      - `done {cached}`
    - Every stream ends with exactly one `done`, or with `error` or `needs_setup` (terminal).
12. **Analyzer data paths:**
    - `TA_EDICT_PATH` (the edict2 file) and `TA_CONJUGATIONS_PATH` (the desktop `Conjugations.txt`, JSON).
    - Missing edict means JParser reports `needs_setup` with the edrdg.org download hint. A missing conjugations file means JParser runs with direct matches only, as the desktop does.
    - MeCab glosses come from the same edict index when it is present.

## Review Focus

1. **Client disconnect mid-stream.** Closing the browser's `EventSource` while Ollama is streaming must close the upstream request, and no partial result may reach `mt_cache`. Tested in Task 4 (translator closes) and Task 7 (no cache row).
2. **Failures never cache and never leak.** A 403 or 5xx from DeepL, LibreTranslate or Ollama becomes an `error` event naming the backend and the HTTP status, never the key. Nothing is cached. Tested in Tasks 3, 4 and 7.
3. **Tenancy:**
   - Another user's `document_id` is a 404.
   - Another user's `profile_id` is a 422.
   - User B's stream never uses user A's DeepL key or Ollama URL.
   - Tested in Task 7.
4. **Hostile or empty text:**
   - A line that is blank or only `%`/`$` makes no backend call.
   - Text containing `\n\n`, quotes, or `event:` arrives intact inside JSON `data`.
   - Tested in Task 7.
5. **Unconfigured backends degrade visibly:**
   - DeepL with no key, LibreTranslate with no URL, Ollama with no model, JParser with no edict, MeCab not installed: each yields `needs_setup` with a human message in `/mt/backends` and as a terminal SSE event, never a 500.
   - Tested in Tasks 5–7.

```python
"""The aggregator's shared vocabulary (spec §8): SSE events, setup and failure signals."""

import json

Event = tuple[str, dict]  # (type, data); types are listed in the plan's ruling 11

HTTP_BACKENDS = ("deepl", "libretranslate", "ollama")
ANALYZERS = {"mecab", "jparser"}
ALL_BACKENDS = HTTP_BACKENDS + ("mecab", "jparser")


def sse(event: Event) -> str:
    kind, data = event
    return f"event: {kind}\ndata: {json.dumps(data, ensure_ascii=False)}\n\n"


class NeedsSetup(Exception):
    """The backend is not configured for this user or server; the message says how."""


class BackendError(Exception):
    """A backend call failed. The message is shown to the user: never put a secret in it."""
```

LANGUAGES: dict[str, str] = {

    "ja": "Japanese",
    # … every remaining _GOOGLE_CODES pair, in the desktop's order

    "ja": "JA",

    return f"{name} ({code})" if code in LANGUAGES else name

  **`api/mt/cache.py`:**

```python
"""mt_cache (spec §8): results keyed by backend, language pair and the source's SHA-256,
so revisiting a line costs nothing. First write wins."""

import hashlib

from sqlalchemy import select
from sqlalchemy.dialects.postgresql import insert
from sqlalchemy.orm import Session

from api.models import MtCache


def key_text(text: str) -> str:
    return hashlib.sha256(text.encode("utf-8")).hexdigest()


def get(db: Session, backend: str, src: str, dst: str, text: str) -> str | None:
    return db.scalar(
        select(MtCache.result_text).where(
            MtCache.backend == backend,
            MtCache.source_lang == src,
            MtCache.target_lang == dst,
            MtCache.source_sha256 == key_text(text),
        )
    )


def put(db: Session, backend: str, src: str, dst: str, text: str, result: str) -> None:
    db.execute(
        insert(MtCache)
        .values(backend=backend, source_lang=src, target_lang=dst,
                source_sha256=key_text(text), result_text=result)
        .on_conflict_do_nothing()
    )
```

  If `MtCache.backend` is `String(40)`, the `ollama:<model>:<hash>` key can overflow it. Task 7 truncates the model part so the key fits. Check the width in `api/models/content.py`.

"""DeepL (desktop ta/translators/deepl.py), over its REST API instead of the SDK."""

import httpx

from api.mt.base import BackendError, NeedsSetup
from api.mt.languages import deepl_code

TIMEOUT = 15  # seconds, as the desktop


async def translate(client: httpx.AsyncClient, key: str, text: str, src: str, dst: str) -> str:
    if not key:
        raise NeedsSetup("Add your DeepL API key under Settings → Machine translation.")
    target = deepl_code(dst)
    if not target:
        raise NeedsSetup(f"DeepL cannot translate into {dst}.")
    host = "https://api-free.deepl.com" if key.endswith(":fx") else "https://api.deepl.com"

```python
"""Ollama (desktop ta/translators/ollama.py): streams /api/chat tokens as they arrive."""

import json
from collections.abc import AsyncIterator

import httpx

from api.mt.base import BackendError, Event, NeedsSetup
from api.mt.languages import display

DEFAULT_SYSTEM_PROMPT = (
    # verbatim from the desktop ta/config/settings.py DEFAULT_OLLAMA_SYSTEM_PROMPT
    "You are a professional {src} to {dst} translator.\n\n"
    "Translate the following {src} text to {dst}.\n\n"
    "Requirements:\n"
    "* Preserve the original meaning, tone, nuance, and intent.\n"
    "* Produce natural, grammatically correct {dst}.\n"
    "* Return only the translation — no explanations, notes, or commentary."
)
# Model load + prompt eval can take minutes before the first token (desktop comment).
TIMEOUT = httpx.Timeout(10, read=300)


def _headers(token: str) -> dict:
    return {"Authorization": f"Bearer {token}"} if token else {}


async def available(client: httpx.AsyncClient, url: str, token: str) -> str | None:
    try:
        r = await client.get(f"{url.rstrip('/')}/api/tags", headers=_headers(token), timeout=3)
    except httpx.HTTPError:
        return f"Ollama is unreachable at {url}."
    return None if r.status_code == 200 else f"Ollama answered HTTP {r.status_code}."


async def stream(
    client: httpx.AsyncClient, url: str, token: str, model: str, system_prompt: str,
    text: str, src: str, dst: str,
) -> AsyncIterator[Event]:
    if not model:
        raise NeedsSetup("Choose an Ollama model under Settings → Machine translation.")
    system = system_prompt.replace("{src}", display(src)).replace("{dst}", display(dst))
    payload = {
        "model": model, "stream": True, "think": True,
        "messages": [{"role": "system", "content": system}, {"role": "user", "content": text}],
    }
    try:
        async with client.stream("POST", f"{url.rstrip('/')}/api/chat", json=payload,
                                 headers=_headers(token), timeout=TIMEOUT) as r:
            if r.status_code != 200:
                await r.aread()
                try:
                    detail = r.json().get("error", "")
                except ValueError:
                    detail = ""
                raise BackendError(f"Ollama answered HTTP {r.status_code}"
                                   + (f": {detail}" if detail else ""))
            async for line in r.aiter_lines():
                if not line.strip():
                    continue
                obj = json.loads(line)
                if obj.get("done"):
                    return
                message = obj.get("message", {})
                if message.get("thinking"):
                    yield ("thinking", {"text": message["thinking"]})
                if message.get("content"):
                    yield ("chunk", {"text": message["content"]})
    except httpx.HTTPError as exc:
        raise BackendError(f"Ollama is unreachable ({type(exc).__name__})") from exc
```

  Leaving the `async with` closes the response, which stops generation server-side (the desktop comment). That holds both when the consumer calls `aclose()` and when an exception is raised.

from api.core import nouns
from api.mt import jparser
from api.mt.base import NeedsSetup


def run(text: str) -> list[dict]:
    try:
        tagger = nouns.tagger()
    except nouns.Unavailable as exc:
        raise NeedsSetup(str(exc)) from exc
    path = jparser._edict_path()
    index = jparser.load_index(path) if path else None
    out = []
    with nouns._lock:  # one MeCab tagger, not thread-safe (phase 4)
        words = list(tagger(text))

        reading = getattr(f, "kana", "") or getattr(f, "pron", "") or ""

        out.append({

            "pos": getattr(f, "pos1", "") or "", "gloss": hit.gloss if hit else "",
            "tense": "", "base_form": "", "matched": True,
        })
    return out
