## Global Constraints

- **Routers:**
  - Every router is built with `api_router()`. Handlers `flush()` and never `commit()`.
  - `tests/test_commit_boundary.py` must keep passing.
- **Commits outside the request:** two sanctioned exceptions to "handlers never commit":
  - the job worker, which commits in its own `SessionLocal()` sessions (`api/jobs.py`);
  - the existing `/mt/stream` cache write.
  - Nothing else commits.
- **Tenancy:**
  - Fetch user-owned rows with `scoped()`; an id in a body or query goes through `owned_ref()`.
  - Another user's id is a 404, never a 403. A job only ever touches rows owned by `job.user_id`.
- **Uploads** (spec §6):
  - Size-capped with `read_capped`.
  - EPUB/ZIP: reject absolute paths and `..` entries, and cap the total uncompressed size.
  - Every bad upload is a 4xx, never a 500, and writes nothing.
- **Network:**
  - No live network in tests. HTTP goes through an injected `httpx.Client`; tests use `httpx.MockTransport` with recorded HTML (spec §12).
  - Fetching only ever reaches `*.syosetu.com`, redirects included.
- **Module size:** no Python module over ~400 lines; no React component file over ~300.
- **Migrations:** autogenerated only (`alembic revision --autogenerate`); every model is imported in `api/models/__init__.py`.
- **API types:** run `npm run gen:api` in `web/` after API changes the SPA consumes. Commit `web/src/api/schema.d.ts`; `web/openapi.json` is gitignored.
- **Environment:**
  - venv `.venv` with `.[dev,mecab]`, and `TA_SECRET_KEY=dev-secret-key-at-least-32-characters-long`.
  - Postgres runs on localhost:5432. Never run `docker compose down`.
  - `pytest -q` prints only dots, so judge a run by its exit code.
- **Commit trailers:** a `Co-Authored-By` line for the authoring model, plus whatever `Claude-Session:` line the executing session's harness specifies. Put one blank line between the subject and the trailers.
- **E2E conventions** (CLAUDE.md):
  - Each spec owns its seeded rows.
  - Seed names must not contain "E2E chapter".
  - The database resets once per run.

## Rulings (user choices marked ✔)

1. ✔ **Phase 6 is split.** 6a (this plan) is jobs plus acquisition plus EPUB build. 6b is WordPress publish, batch publish and scheduling, and statistics.
2. ✔ **`work_sessions` is not written.** Nothing reads it: stats come from `lines.translated_at`. Task 11 records this in the spec.
3. ✔ **EPUB uploads may be up to 64 MiB:**
   - Both Caddy (`/api/epub/*` only) and the API (`MAX_EPUB_BYTES`) enforce it.
   - The total uncompressed size is capped at 256 MiB.
   - Every other upload keeps the 12 MB Caddy cap.
4. ✔ **Batch import is a multi-file upload:** `.txt` files plus an optional single `.csv`. It is not a folder or a ZIP.
5. **Synchronous work.** Only the syosetu series fetch is a job in 6a. Batch TXT import, EPUB import and EPUB build are synchronous requests.
   - **Why:** spec §9 lists them as long-running, but each is CPU-bound for seconds at most. Batch publish (6b) will be the second job kind.
   - **Ceiling:** an EPUB build holds the whole book in memory.
     ```python
     # ponytail: synchronous build, the book in memory; make it a job with a result blob if volumes outgrow a request
     ```
6. **EPUB import uploads the file twice:** once to `POST /epub/inspect` (chapter list) and once to `POST /epub/import` (with the selection). Nothing is staged server-side.
   - **Ceiling:** a 60 MB book crosses the network twice.
     ```python
     # ponytail: re-upload instead of a staged-upload table; stage it if remote users find two uploads slow
     ```
7. **Rate limit:**
   - Every syosetu chapter request, from a job, a single fetch or a re-fetch, goes through one process-wide throttle.
   - The throttle spaces requests `TA_SYOSETU_DELAY_SECONDS` apart (default 5, the desktop's `QThread.sleep(5)`).
   - Index pages are not throttled (the desktop doesn't throttle them), but they are capped at 100 pages.
8. **The series fetch job takes chapter numbers, not URLs.** The worker re-reads the series index from the series' own `syosetu_url` and fetches the selected numbers, so a client can never point the server at a URL.
9. **Redirects** are followed only within `*.syosetu.com`. A request event hook validates every hop before it is sent. `validate_url` checks `urlparse(url).hostname`, not `netloc`, so `https://x.syosetu.com@evil.com/` is refused. This is the one deliberate change to the ported function.
10. **Jobs and restarts:**
    - On startup, a job left `running` becomes `failed` with "interrupted by a server restart; start it again to resume".
    - On shutdown, the running job stops at its next progress point and fails with the same message.
    - The series fetch is idempotent: it skips chapters already in the series, so starting it again resumes.
11. **Job SSE:**
    - `GET /jobs/{id}/events` polls the row once a second in its own session and sends `event: job` with the `JobOut` JSON whenever it changes. It ends after a terminal state (`done`, `failed`, `cancelled`).
    - The client closes its `EventSource` on a terminal state, because a browser reconnects a closed stream on its own.
12. **Batch import order:**
    - Files are imported in `natural_key` order of their names, so `ch2` comes before `ch10`. (The desktop used plain `sorted`.)
    - They are appended after the series' existing chapters (`next_series_order`). The desktop numbered from 0 and could collide with existing chapters.
    - A file whose stem matches an existing document title of the user's is skipped, as on the desktop.
    - A single `.csv` is upserted into a profile named after the CSV's stem, using phase 4's import rules. The desktop replaced the glossary; phase 4 ruled upsert. If a series is chosen, the profile is assigned to it.
13. **EPUB export of a volume with an incomplete chapter is a 409** naming the chapters. The desktop skipped such a volume silently. A chapter with no lines and no images is left out, as on the desktop.

## Review Focus

1. **Hostile archives:**
   - An `.epub` that is not a zip, has an entry with `../` or a leading `/`, declares more than 256 MiB uncompressed, or lacks `container.xml` gets a 422 from both `/epub/inspect` and `/epub/import`.
   - None of them is ever a 500, and nothing is written. Tested in Tasks 5 and 6.
2. **Client-supplied URLs:**
   - `POST /scrape/syosetu` and re-fetch reach only `*.syosetu.com`.
   - `https://x.syosetu.com@evil.com/`, `http://localhost/`, `file:///etc/passwd`, and a syosetu page redirecting to another host are each refused before any request leaves for the bad host.
   - Tested in Tasks 3 and 4.
3. **Cancel and restart mid-job:**
   - Cancelling a series fetch stops after the current chapter, and the chapters fetched so far stay.
   - A server restart marks the running job failed.
   - Starting the fetch again skips what exists.
   - Tested in Tasks 1 and 4.
4. **Partial failures in a batch:** one bad file (not UTF-8, no separator, too many lines) or one bad EPUB chapter does not abort the others. The summary names it, and the good ones are written. Tested in Tasks 6 and 8.
5. **Tenancy:**
   - Another user's job id is a 404 on `GET /jobs/{id}`, `/events` and `/cancel`.
   - Another user's `series_id` in a fetch, batch import or EPUB import is a 404 or 422.
   - Another user's volume is a 404 on EPUB export.
   - Tested in Tasks 2, 4, 6, 7 and 8.

```python
"""The jobs table driver and the in-process worker (spec §9).

One asyncio task, started in the app lifespan, runs one job at a time in the
threadpool. A handler gets a JobContext: its own session (committed at each
progress point, so the work so far and the progress land together) and the job row.
This and the /mt/stream cache write are the only commits outside the request
boundary (CLAUDE.md).

# ponytail: in-process worker, single replica. Swap for arq + Redis when the
# deployment needs more than one API container (spec §9).
"""

import asyncio
import logging
import threading
from collections.abc import Callable
from datetime import UTC, datetime

from fastapi.concurrency import run_in_threadpool
from sqlalchemy import select, update
from sqlalchemy.orm import Session

from api.db import SessionLocal
from api.models import Job

log = logging.getLogger(__name__)

TERMINAL = {"done", "failed", "cancelled"}
INTERRUPTED = "interrupted by a server restart; start it again to resume"
HANDLERS: dict[str, Callable[["JobContext"], dict]] = {}
stopping = threading.Event()  # set by the lifespan on shutdown


class JobError(Exception):
    """A failure the user should read (the message is stored on the job)."""


class Cancelled(Exception):
    """The user cancelled the job; work committed before this point stays."""


class _Interrupted(Exception):
    """The server is shutting down."""


def handler(kind: str):
    def register(fn: Callable[["JobContext"], dict]):
        HANDLERS[kind] = fn
        return fn
    return register


class JobContext:
    def __init__(self, db: Session, job: Job) -> None:
        self.db = db
        self.job = job

    @property
    def params(self) -> dict:
        return self.job.params_json

    def progress(self, done: int, total: int, message: str = "") -> None:
        """Commit the work so far with the progress, then stop if asked to."""
        self.job.progress, self.job.total, self.job.message = done, total, message
        self.db.commit()
        self.db.refresh(self.job)  # sees cancel_requested set by another session
        if stopping.is_set():
            raise _Interrupted
        if self.job.cancel_requested:
            raise Cancelled


def _now() -> datetime:
    return datetime.now(UTC)


def enqueue(db: Session, user_id: int, kind: str, params: dict, total: int = 0) -> Job:
    """Queue a job in the request's session (the route commits it)."""
    job = Job(user_id=user_id, kind=kind, params_json=params, total=total)
    db.add(job)
    db.flush()
    return job


def _claim(db: Session) -> Job | None:
    job = db.scalar(
        select(Job)
        .where(Job.state == "queued")
        .order_by(Job.id)
        .limit(1)
        .with_for_update(skip_locked=True)
    )
    if job is not None:
        job.state, job.started_at = "running", _now()
        db.commit()
    return job


def run_next() -> bool:
    """Run the oldest queued job to completion. False when there was none."""
    with SessionLocal() as db:
        job = _claim(db)
        if job is None:
            return False
        fn = HANDLERS.get(job.kind)
        try:
            if fn is None:
                raise JobError(f"unknown job kind {job.kind!r}")
            result = fn(JobContext(db, job))
            job.state, job.result_json = "done", result or {}
        except Cancelled:
            db.rollback()
            job.state = "cancelled"
        except _Interrupted:
            db.rollback()
            job.state, job.message = "failed", INTERRUPTED
        except JobError as exc:
            db.rollback()
            job.state, job.message = "failed", str(exc)
        except Exception:
            log.exception("job %s (%s) failed", job.id, job.kind)
            db.rollback()
            job.state, job.message = "failed", f"{job.kind} failed"
        job.finished_at = _now()
        db.commit()
        return True


def fail_interrupted() -> int:
    """At startup: a job still marked running died with the previous process."""
    with SessionLocal() as db:
        n = db.execute(
            update(Job)
            .where(Job.state == "running")
            .values(state="failed", message=INTERRUPTED, finished_at=_now())
        ).rowcount
        db.commit()
        return n


async def worker(stop: asyncio.Event, idle: float = 1.0) -> None:
    """Poll for queued jobs until ``stop`` is set."""
    while not stop.is_set():
        try:
            ran = await run_in_threadpool(run_next)
        except Exception:
            log.exception("job worker iteration failed")
            ran = False
        if not ran:
            try:
                await asyncio.wait_for(stop.wait(), idle)
            except TimeoutError:
                pass
```

```python
from fastapi.concurrency import run_in_threadpool

from api import jobs


@asynccontextmanager
async def lifespan(app: FastAPI):
    if not get_settings().run_jobs_worker:
        yield
        return
    await run_in_threadpool(jobs.fail_interrupted)
    jobs.stopping.clear()
    stop = asyncio.Event()
    task = asyncio.create_task(jobs.worker(stop))

    jobs.stopping.set()  # a running job stops at its next progress point
    stop.set()
    await task
```

```python
"""Jobs (spec §9): list, read, cancel, and follow one over SSE."""

import asyncio

from fastapi import Depends, Query
from fastapi.concurrency import run_in_threadpool
from fastapi.responses import StreamingResponse
from sqlalchemy import select
from sqlalchemy.orm import Session

from api.db import SessionLocal
from api.deps import current_user, db_session, scoped
from api.jobs import TERMINAL
from api.models import Job, User
from api.mt.base import sse
from api.routing import api_router
from api.schemas.jobs import JobOut

router = api_router(prefix="/jobs", tags=["jobs"])

POLL_SECONDS = 1.0


@router.get("", response_model=list[JobOut])
def list_jobs(
    active: bool = False,
    series_id: int | None = None,
    user: User = Depends(current_user),
    db: Session = Depends(db_session),
) -> list[Job]:
    q = select(Job).where(Job.user_id == user.id)
    if active:
        q = q.where(Job.state.in_(("queued", "running")))
    if series_id is not None:
        q = q.where(Job.params_json["series_id"].as_integer() == series_id)
    return list(db.scalars(q.order_by(Job.id.desc()).limit(50)))


@router.get("/{job_id}", response_model=JobOut)
def get_job(job_id: int, user: User = Depends(current_user), db: Session = Depends(db_session)) -> Job:
    return scoped(db, Job, job_id, user.id)


@router.post("/{job_id}/cancel", response_model=JobOut)
def cancel_job(
    job_id: int, user: User = Depends(current_user), db: Session = Depends(db_session)
) -> Job:
    """A queued job is cancelled at once; a running one stops at its next progress
    point (the worker checks cancel_requested). Terminal jobs are left as they are."""
    scoped(db, Job, job_id, user.id)
    job = db.get(Job, job_id, with_for_update=True, populate_existing=True)
    if job.state == "queued":
        job.state, job.finished_at = "cancelled", func.now()
    elif job.state == "running":
        job.cancel_requested = True
    db.flush()
    return job


def _snapshot(job_id: int) -> dict:
    with SessionLocal() as s:
        return JobOut.model_validate(s.get(Job, job_id, populate_existing=True)).model_dump(mode="json")


@router.get("/{job_id}/events")
async def job_events(
    job_id: int, user: User = Depends(current_user), db: Session = Depends(db_session)
) -> StreamingResponse:
    await run_in_threadpool(scoped, db, Job, job_id, user.id)

    async def frames():
        last = None
        while True:
            snap = await run_in_threadpool(_snapshot, job_id)
            if snap != last:
                yield sse(("job", snap))
                last = snap
            if snap["state"] in TERMINAL:
                return
            await asyncio.sleep(POLL_SECONDS)

    return StreamingResponse(
        frames(), media_type="text/event-stream",
        headers={"Cache-Control": "no-cache", "X-Accel-Buffering": "no"},
    )
```

```python
"""Syosetu fetching, from the desktop translation_assistant/scraper.py: URL checks and
the fetch_* functions. The QThread workers are gone (the jobs worker replaces them).
HTTP goes through an injected httpx.Client so tests replay recorded HTML (spec §12)."""

import threading
import time
from urllib.parse import urljoin, urlparse

import httpx
from bs4 import BeautifulSoup

_ALLOWED_SUFFIX = ".syosetu.com"
_UA = (
    "Mozilla/5.0 (X11; Linux x86_64) AppleWebKit/537.36 "
    "(KHTML, like Gecko) Chrome/120.0 Safari/537.36"
)
TIMEOUT = 10
MAX_INDEX_PAGES = 100  # ours: a next-link loop must not run forever


class ScrapeError(Exception):
    """Syosetu could not be reached or answered with an error."""


def validate_url(url: str) -> None:
    # hostname, not the desktop's netloc: "x.syosetu.com@evil.com" has that netloc suffix
    parsed = urlparse(url)
    host = (parsed.hostname or "").lower()
    if parsed.scheme not in ("http", "https") or not host.endswith(_ALLOWED_SUFFIX):
        raise ValueError("Only syosetu.com URLs are supported")


def _check_request(request: httpx.Request) -> None:
    validate_url(str(request.url))  # every hop, redirects included, before it is sent


def client(transport: httpx.BaseTransport | None = None) -> httpx.Client:
    return httpx.Client(
        transport=transport, timeout=TIMEOUT, follow_redirects=True,
        headers={"User-Agent": _UA}, cookies={"over18": "yes"},
        event_hooks={"request": [_check_request]},
    )


def _get(c: httpx.Client, url: str) -> str:
    validate_url(url)
    try:
        r = c.get(url)
    except httpx.HTTPError as exc:
        raise ScrapeError(f"could not reach {urlparse(url).hostname} ({type(exc).__name__})") from exc
    if r.status_code != 200:
        raise ScrapeError(f"{urlparse(url).hostname} answered HTTP {r.status_code}")
    return r.text


_lock = threading.Lock()
_last = 0.0


def throttle(delay: float) -> None:
    """Space chapter requests at least ``delay`` seconds apart, process-wide, so
    concurrent jobs cannot defeat the desktop's rate limit (spec §9)."""
    global _last
    with _lock:
        wait = _last + delay - time.monotonic()
        if wait > 0:
            time.sleep(wait)
        _last = time.monotonic()
```

```python
"""The syosetu series fetch job (desktop SeriesFetchWorker + FetchSeriesDialog).

Takes chapter numbers, never URLs (plan ruling 8): the index is re-read from the
series' own syosetu_url. Chapters already in the series are skipped, so a rerun
resumes an interrupted fetch (ruling 10)."""

from sqlalchemy import select

from api.config import get_settings
from api.core import scrape
from api.core.text import build_new_file, lines_to_db_rows, parse_file_content
from api.jobs import JobContext, JobError, handler
from api.library import check_line_count, write_lines
from api.models import Document, Series

http_client = scrape.client  # the seam tests replace


def existing_orders(db, series_id: int) -> set[int]:
    return set(db.scalars(select(Document.series_order).where(Document.series_id == series_id)))


@handler("syosetu_fetch")
def fetch_series(ctx: JobContext) -> dict:
    series = ctx.db.get(Series, ctx.params["series_id"])
    if series is None or series.user_id != ctx.job.user_id:
        raise JobError("the series no longer exists")
    wanted = set(ctx.params["nums"])
    delay = get_settings().syosetu_delay_seconds
    ctx.progress(0, len(wanted), "Reading the chapter list")
    added, skipped, errors = 0, 0, []
    with http_client() as c:
        try:
            index = [ch for ch in scrape.fetch_series_index(c, series.syosetu_url)
                     if ch["num"] in wanted]
        except (ValueError, scrape.ScrapeError) as exc:
            raise JobError(f"could not read the chapter list: {exc}") from exc
        have = existing_orders(ctx.db, series.id)
        for i, ch in enumerate(index, start=1):
            if ch["num"] in have:
                skipped += 1
            else:
                try:
                    title, content = scrape.fetch_syosetu(c, ch["url"], delay=delay)
                    raw, translated, _ = parse_file_content(build_new_file(content))
                    check_line_count(raw)
                except Exception as exc:  # one bad chapter must not stop the rest
                    errors.append({"num": ch["num"], "message": str(exc) or type(exc).__name__})
                else:
                    doc = Document(
                        user_id=series.user_id, series_id=series.id, title=title or ch["title"],
                        chapter_title=title or ch["title"], series_order=ch["num"],
                        source_url=ch["url"],
                    )
                    ctx.db.add(doc)
                    ctx.db.flush()
                    write_lines(ctx.db, doc.id, lines_to_db_rows(raw, translated))
                    added += 1
            ctx.progress(i, len(index), f"Chapter {ch['num']}")
    missing = sorted(wanted - {ch["num"] for ch in index})
    return {"added": added, "skipped": skipped, "errors": errors, "missing": missing}
```

```python
MAX_UNCOMPRESSED = 256 * 1024 * 1024  # ours (spec §6): cap what a book may expand to


def _check_archive(zf: zipfile.ZipFile) -> None:
    """Refuse absolute and parent-relative entry names and oversized archives
    (spec §6). Entries are only ever read by name, never extracted to disk, but a
    book that names one is not one we should trust with anything else."""
    total = 0
    for info in zf.infolist():
        parts = info.filename.replace("\\", "/").split("/")
        if info.filename.startswith(("/", "\\")) or ".." in parts:
            raise EpubError(f"unsafe path in EPUB: {info.filename!r}")
        total += info.file_size
        if total > MAX_UNCOMPRESSED:
            raise EpubError(f"EPUB expands to more than {MAX_UNCOMPRESSED // (1024 * 1024)} MB")
```

     - a non-blank `volume_title`;
     - `1 <= len(hrefs) <= MAX_CHAPTERS`.

  4. **Resolve the series:**
     - a `series_id` goes through `owned_ref(db, Series, series_id, user.id, "series_id")`;
     - otherwise, get or create `Series(user_id=user.id, title=series_title.strip())`.

     - Title in `already`: append the title to `skipped`.

```python
@router.get("/volumes/{volume_id}/export/epub")
def export_volume(
    volume_id: int, user: User = Depends(current_user), db: Session = Depends(db_session)
) -> Response:
    # ponytail: synchronous build, the book in memory; make it a job with a result blob if volumes outgrow a request
    volume = scoped_volume(db, volume_id, user.id)
    docs = db.scalars(select(Document).where(Document.volume_id == volume.id)
                      .order_by(Document.series_order, Document.id))
    chapters, cover, incomplete = [], None, []
    for doc in docs:
        raw, translated = line_arrays(db, doc.id)
        images = list(db.scalars(select(DocumentImage).where(DocumentImage.document_id == doc.id)
                                 .order_by(DocumentImage.anchor_position, DocumentImage.id)))
        inline = [im for im in images if not im.is_cover and not im.exclude_export]
        if cover is None:
            row = next((im for im in images if im.is_cover), None)
            if row is not None:
                media = mimetypes.guess_type(row.src_path)[0] or "application/octet-stream"
                cover = {"data": row.data, "media_type": media}
        if not raw and not inline:
            continue  # nothing to show; it must not block the volume (desktop)
        if raw and calculate_progress(raw, translated)[0] < 100:
            incomplete.append(doc.chapter_title or doc.title)
            continue
        refs = [{"anchor_position": im.anchor_position, "src_path": im.src_path} for im in inline]
        chapters.append((
            doc.chapter_title or doc.title,
            build_epub_content(raw, translated, refs),
            [{"src_path": im.src_path, "data": im.data} for im in inline],
        ))
    if incomplete:
        raise HTTPException(status.HTTP_409_CONFLICT,
                            "not fully translated: " + ", ".join(incomplete))
    if not chapters:
        raise _unprocessable("the volume has no chapters with content")
    data = build_epub(
        volume.epub_title or volume.title or volume.series.title, chapters,
        language=volume.epub_language or "en", cover=cover,
        creator=volume.epub_author, illustrator=volume.epub_illustrator,
        publisher=volume.epub_publisher, identifier=volume.epub_identifier,
    )
    name = f"{sanitize_filename(volume.title) or 'volume'}.epub"
    return Response(data, media_type="application/epub+zip", headers=attachment(name))
```
