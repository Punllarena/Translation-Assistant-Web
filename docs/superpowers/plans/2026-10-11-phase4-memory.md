## Global Constraints

- Every router is built with `api_router()` (`api/routing.py`). Handlers `flush()` and never `commit()`.
- Fetch user-owned rows by id with `scoped()`. Ids named in a request body or query go through `owned_ref()`. Another user's id is a 404, never a 403.
- Text bound for Postgres goes through `NoNulStr` (`api/schemas/lines.py`), because NUL in a text column is a 500.
- No Python module over ~400 lines.
- Migrations are autogenerated (`alembic revision --autogenerate`), never hand-patched.

## Rulings (decided while planning)

1. **TM is an exact match.** The spec says "resembles… ranked by similarity" but also "the ported `find_tm_matches` query". That query is exact equality on `raw_text`, newest document first, limit 5, and the port wins. A hash index on `lines.raw_text` keeps it cheap. Cost if wrong: fuzzy ranking is added later behind the same endpoint.
2. **Phrase suggestions run synchronously in the request, not as a job.** The jobs table arrives in phase 6, and MeCab runs at roughly 10k lines a second, so a series of 300 chapters takes a few seconds. `# ponytail:` ceiling: move it into a job in phase 6 if series grow.
3. **MeCab is an optional extra**: `pip install -e ".[mecab]"` (fugashi + unidic-lite). When it is absent, the endpoint returns `available: false` with the install hint, which is the spec §8 degradation contract. CI installs it.
4. **Find and replace matches literal text** (`re.escape`), optionally ignoring case, over translated text only, like the desktop. The reviewed batch sends each target's `before` text. The server applies a target only when the line still holds exactly that text and skips it otherwise. That is what "reviewed, not blind" means here.
5. **A glossary upsert keeps the entry's position.** The desktop `INSERT OR REPLACE` moved it to the end, but an edit should not reorder the list.
6. **The series-phrases shortcut (Ctrl+Shift+P) is dropped.** It is Firefox's private window. The tools live on the series page, and the editor links there.
7. **Carry-over items:**
   - Folded in:
     - Partial line saves.
     - Persisting the profile switch.
     - The noisy live region.
     - The sticky find mark.
     - Extracting `useFind`.
     - Enter auto-repeat.
     - The Edit Source navigation guard.
     - The third Playwright flow.
   - Still deferred: two tabs, last write wins (needs base-text versioning). The CI e2e job stays untested until there is a remote.
8. **Enter auto-repeat:** a held Enter runs `save_next` once. This deliberately breaks desktop parity: auto-repeat skipped lines unseen.
9. **Persisting the profile switch:**
   - For a chapter in a series, the switch sets the series' profile.
   - For a loose chapter, it saves the user setting `profile_used`.
   - The server's fallback order becomes: explicit choice, then series profile, then `profile_used`, then default, then oldest.

## Review Focus

1. **Literal find and replace.** A needle or replacement holding regex syntax (`.*`, `$1`, `\1`, `\n`, `(`) is plain text on both sides. Tested in Task 3.
2. **Hostile input to find.** A NUL in the query, or a 10k-char needle, gets a 422, never a 500. Tested in Task 3.
3. **Stale review.** A line edited between search and replace is skipped and counted, never overwritten with a replacement computed from old text. Tested in Task 3.
4. **CSV edge cases:**
   - A BOM, CRLF line ends, or a comma inside the translation (`a,b,c` gives phrase `a`, translation `b,c`) all import correctly.
   - A file that is not UTF-8 gets a 422.
   - A phrase repeated within the file keeps the last translation and does not 500.
   - Tested in Task 1.
5. **Tenancy:**
   - TM never returns another user's lines.
   - Glossary, find, replace and suggestions answer 404 for another user's profile or series.
   - A replace target naming a document outside the series is skipped.
   - Tested in Tasks 1–4.

```python
def load_glossary(text: str) -> list[tuple[str, str]]:
    """From the desktop ``core.load_glossary``, taking the file's text instead of a path.

    Lines are "phrase,translation"; a missing translation is "". Blank lines are ignored.
    """
    result: list[tuple[str, str]] = []
    for line in text.removeprefix("﻿").splitlines():
        line = line.strip()
        if not line:
            continue
        parts = line.split(",", 1)
        result.append((parts[0], parts[1] if len(parts) > 1 else ""))
    return result
```

```python
from pydantic import BaseModel, ConfigDict, Field, field_validator, model_validator

from api.schemas.lines import NoNulStr

MAX_PHRASE_CHARS = 500


def underscored(translation: str) -> str:
    """The desktop stores a glossary translation with spaces as underscores."""
    return translation.replace(" ", "_")


class GlossaryIn(BaseModel):
    phrase: NoNulStr = Field(min_length=1, max_length=MAX_PHRASE_CHARS)
    translation: NoNulStr = Field(max_length=MAX_PHRASE_CHARS)

    @field_validator("translation")
    @classmethod
    def _underscores(cls, v: str) -> str:
        return underscored(v)


class GlossaryList(BaseModel):
    entries: list[GlossaryIn] = Field(max_length=10_000)

    @model_validator(mode="after")
    def _unique(self) -> "GlossaryList":
        phrases = [e.phrase for e in self.entries]
        if len(set(phrases)) != len(phrases):
            raise ValueError("entries: a phrase is listed more than once")
        return self


class GlossaryOut(BaseModel):
    model_config = ConfigDict(from_attributes=True)

    id: int
    phrase: str
    translation: str
    sort_order: int


class ImportResult(BaseModel):
    added: int
    updated: int
    skipped: int  # rows with an empty or over-long phrase, or a NUL
```

```python
from fastapi import Depends, File, HTTPException, UploadFile, status
from sqlalchemy import delete, func, select
from sqlalchemy.dialects.postgresql import insert
from sqlalchemy.orm import Session

from api.core.text import load_glossary
from api.deps import current_user, db_session, scoped
from api.models import GlossaryEntry, Profile, User
from api.routing import api_router
from api.schemas.glossary import (
    MAX_PHRASE_CHARS,
    GlossaryIn,
    GlossaryList,
    GlossaryOut,
    ImportResult,
    underscored,
)
from api.uploads import read_capped

router = api_router(prefix="/profiles/{profile_id}/glossary", tags=["glossary"])

MAX_CSV_BYTES = 1 << 20  # a glossary CSV is a few KB; 1 MiB is generous


def _entries(db: Session, profile_id: int) -> list[GlossaryEntry]:
    return list(
        db.scalars(
            select(GlossaryEntry)
            .where(GlossaryEntry.profile_id == profile_id)
            .order_by(GlossaryEntry.sort_order, GlossaryEntry.id)
        )
    )


def _upsert(db: Session, profile_id: int, pairs: dict[str, str]) -> int:
    """Insert new phrases at the end and update existing ones in place (ruling 5).
    Returns how many were new."""
    existing = set(
        db.scalars(
            select(GlossaryEntry.phrase).where(
                GlossaryEntry.profile_id == profile_id, GlossaryEntry.phrase.in_(pairs)
            )
        )
    )
    start = db.scalar(
        select(func.coalesce(func.max(GlossaryEntry.sort_order), -1)).where(
            GlossaryEntry.profile_id == profile_id
        )
    ) + 1
    stmt = insert(GlossaryEntry).values(
        [
            {"profile_id": profile_id, "phrase": p, "translation": t, "sort_order": start + i}
            for i, (p, t) in enumerate(pairs.items())
        ]
    )
    db.execute(
        stmt.on_conflict_do_update(
            index_elements=["profile_id", "phrase"],
            set_={"translation": stmt.excluded.translation},
        )
    )
    return len(pairs) - len(existing)


@router.get("", response_model=list[GlossaryOut])
def list_glossary(
    profile_id: int, user: User = Depends(current_user), db: Session = Depends(db_session)
) -> list[GlossaryEntry]:
    return _entries(db, scoped(db, Profile, profile_id, user.id).id)


@router.put("", response_model=list[GlossaryOut])
def replace_glossary(
    profile_id: int,
    body: GlossaryList,
    user: User = Depends(current_user),
    db: Session = Depends(db_session),
) -> list[GlossaryEntry]:
    """The desktop set_glossary: the whole list, in order (edit, delete and reorder)."""
    profile = scoped(db, Profile, profile_id, user.id)
    db.execute(delete(GlossaryEntry).where(GlossaryEntry.profile_id == profile.id))
    db.add_all(
        GlossaryEntry(profile_id=profile.id, phrase=e.phrase, translation=e.translation, sort_order=i)
        for i, e in enumerate(body.entries)
    )
    db.flush()
    return _entries(db, profile.id)


@router.post("", response_model=GlossaryOut)
def add_phrase(
    profile_id: int,
    body: GlossaryIn,
    user: User = Depends(current_user),
    db: Session = Depends(db_session),
) -> GlossaryEntry:
    profile = scoped(db, Profile, profile_id, user.id)
    _upsert(db, profile.id, {body.phrase: body.translation})
    return db.scalar(
        select(GlossaryEntry).where(
            GlossaryEntry.profile_id == profile.id, GlossaryEntry.phrase == body.phrase
        )
    )


@router.post("/import", response_model=ImportResult)
def import_csv(
    profile_id: int,
    file: UploadFile = File(...),
    user: User = Depends(current_user),
    db: Session = Depends(db_session),
) -> ImportResult:
    profile = scoped(db, Profile, profile_id, user.id)
    try:
        text = read_capped(file, MAX_CSV_BYTES).decode("utf-8")
    except UnicodeDecodeError as exc:
        raise HTTPException(status.HTTP_422_UNPROCESSABLE_CONTENT, "the file is not UTF-8") from exc
    pairs: dict[str, str] = {}  # a phrase repeated in the file: the last row wins
    skipped = 0
    for phrase, translation in load_glossary(text):
        bad = not phrase or "\x00" in phrase + translation
        if bad or len(phrase) > MAX_PHRASE_CHARS or len(translation) > MAX_PHRASE_CHARS:
            skipped += 1
            continue
        pairs[phrase] = underscored(translation)
    added = _upsert(db, profile.id, pairs) if pairs else 0
    db.flush()
    return ImportResult(added=added, updated=len(pairs) - added, skipped=skipped)
```

```python
        select(Line.raw_text).where(Line.document_id == doc.id, Line.line_number == line_number)

        return []

        select(Line.translated_text, Document.id, Document.title, Document.updated_at)
        .join(Document, Document.id == Line.document_id)
        .where(
            Document.user_id == user.id,
            Line.raw_text == raw,
            Line.translated_text != "",
            Line.document_id != doc.id,
        )
        .order_by(Document.updated_at.desc(), Line.id.desc())
        .limit(TM_LIMIT)
    )

        TmMatch(translated_text=t, document_id=i, document_title=title, updated_at=u)
        for t, i, title, u in rows
```

```python
def needle_pattern(needle: str, case_sensitive: bool) -> re.Pattern[str]:
    """Find and replace in a series (desktop FindReplaceDialog): literal text, optionally
    ignoring case."""
    return re.compile(re.escape(needle), 0 if case_sensitive else re.IGNORECASE)


def replace_all(pattern: re.Pattern[str], text: str, replacement: str) -> str:
    """Every match replaced by `replacement` taken literally (no \\1 or $1 expansion)."""
    return pattern.sub(lambda _m: replacement, text)
```

```python
MAX_MATCHES = 1000

Needle = Annotated[NoNulStr, Query(min_length=1, max_length=MAX_NEEDLE_CHARS)]
Replacement = Annotated[NoNulStr, Query(max_length=MAX_NEEDLE_CHARS)]


@router.get("/series/{series_id}/find", response_model=FindResult)
def find_in_series(
    series_id: int,
    q: Needle,
    replace: Replacement = "",
    case_sensitive: bool = False,
    user: User = Depends(current_user),
    db: Session = Depends(db_session),
) -> FindResult:
    """The desktop find_in_series, with each match's replaced text as a preview."""
    series = scoped(db, Series, series_id, user.id)
    pattern = needle_pattern(q, case_sensitive)
    text = Line.translated_text
    # SQL narrows the rows; the pattern decides (Postgres lower() and Python's case
    # folding can disagree on rare characters).
    narrow = text.contains(q, autoescape=True) if case_sensitive else text.icontains(q, autoescape=True)
    rows = db.execute(
        select(Line.document_id, Document.title, Line.line_number, text)
        .join(Document, Document.id == Line.document_id)
        .where(Document.series_id == series.id, narrow)
        .order_by(Document.series_order, Document.id, Line.line_number)
    )
    matches: list[FindMatch] = []
    for doc_id, title, number, before in rows:
        if not pattern.search(before):
            continue
        if len(matches) == MAX_MATCHES:
            return FindResult(matches=matches, truncated=True)
        matches.append(
            FindMatch(document_id=doc_id, title=title, line_number=number, before=before,
                      after=replace_all(pattern, before, replace))
        )
    return FindResult(matches=matches, truncated=False)


@router.post("/series/{series_id}/replace", response_model=ReplaceResult)
def replace_in_series(
    series_id: int,
    body: ReplaceRequest,
    user: User = Depends(current_user),
    db: Session = Depends(db_session),
) -> ReplaceResult:
    """Apply a reviewed batch in one transaction (ruling 4). A target is replaced only if
    its line still holds the text the user reviewed; anything else is skipped."""
    series = scoped(db, Series, series_id, user.id)
    pattern = needle_pattern(body.find, body.case_sensitive)
    wanted = {(t.document_id, t.line_number): t.before for t in body.targets}
    replaced, touched = 0, set()
    if wanted:
        lines = db.scalars(
            select(Line)
            .join(Document, Document.id == Line.document_id)
            .where(
                Document.series_id == series.id,
                tuple_(Line.document_id, Line.line_number).in_(list(wanted)),
            )
            .with_for_update(of=Line)
        )
        for line in lines:
            before = wanted[(line.document_id, line.line_number)]
            if line.translated_text != before or not pattern.search(before):
                continue
            line.translated_text = replace_all(pattern, before, body.replace)
            if not line.translated_text:
                line.translated_at = None  # as save_lines: an emptied line is untranslated
            replaced += 1
            touched.add(line.document_id)
    if touched:
        db.execute(update(Document).where(Document.id.in_(touched)).values(updated_at=func.now()))
    db.flush()
    return ReplaceResult(replaced=replaced, skipped=len(wanted) - replaced)
```

```ts
import { useEffect, useMemo, useRef, useState } from "react";
import { findHits, firstFrom, wrapStep } from "./find";
import type { Row } from "./rows";

export function useFind(rows: Row[], texts: Record<number, string>, active: number, activate: (i: number) => void) {
  const [find, setFind] = useState({ open: 0, needle: "", at: -1 });
  const hits = useMemo(
    () => findHits(rows.flatMap((r) => r.kind === "line"
      ? [{ index: r.index, source: r.line.display_text, translation: texts[r.line.line_number] ?? "" }]
      : []), find.needle),
    [rows, texts, find.needle],
  );
  const at = find.at < hits.length ? find.at : -1;
  const hit = find.open && at >= 0 ? hits[at] : null;
  const stepped = useRef(false); // the next editor mount comes from a find step: leave focus in the bar
  useEffect(() => { stepped.current = false; }, [active]);
  const step = (dir: 1 | -1) => {
    const next = at < 0 && dir === 1 ? firstFrom(hits, active) : wrapStep(at, hits.length, dir);
    setFind((f) => ({ ...f, at: next }));
    if (hits[next] && hits[next].index !== active) {
      stepped.current = true;
      activate(hits[next].index);
    }
  };
  return {
    open: find.open, needle: find.needle, at, total: hits.length, hit, stepped, step,
    show: () => setFind((f) => ({ ...f, open: f.open + 1 })),
    close: () => { stepped.current = false; setFind((f) => ({ ...f, open: 0, at: -1 })); },
    setNeedle: (needle: string) => setFind((f) => ({ ...f, needle, at: -1 })),
  };
}
```

```ts
export type Row = { phrase: string; translation: string };

export function moveRow(rows: Row[], i: number, dir: -1 | 1): Row[] {
  const j = i + dir;
  if (j < 0 || j >= rows.length) return rows;
  const next = rows.slice();
  [next[i], next[j]] = [next[j], next[i]];
  return next;
}
```
